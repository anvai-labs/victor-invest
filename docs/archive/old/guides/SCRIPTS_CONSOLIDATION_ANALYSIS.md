## Overlap Analysis

### High Overlap - Sector Timeline Generation:

**3 scripts doing similar things:**

1. `generate_sector_timelines.py` (390 lines)
   - Reads `sector_trends_data.json`
   - Generates text reports per sector
   - Calculates change/volatility

2. `generate_multiples_timeline.py` (180+ lines)
   - Queries `sector_multiples_history` table
   - Creates matrix view (sectors × years)
   - Outputs to stdout/file

3. `generate_sector_timeline_html.py` (470 lines, NEW)
   - Queries `sector_multiples_history` table
   - Generates SVG charts (P/E, P/S, P/B)
   - Creates HTML report

**Recommendation:** Consolidate into single script with output format option:
```bash
python scripts/sector_timeline.py --format html --output docs/
python scripts/sector_timeline.py --format json --output /tmp/
python scripts/sector_timeline.py --format text --output /tmp/
```

## Recommended Consolidation Approach

### 1. Create Unified Data Initialization Script

**`scripts/init_data.py`** - Single entry point for all data population:

```bash
# Initialize all data in correct order
python scripts/init_data.py --full

# Or step by step
python scripts/init_data.py --step symbols      # Symbol table
python scripts/init_data.py --step classifications  # Sector/industry
python scripts/init_data.py --step sec-data     # SEC company facts
python scripts/init_data.py --step shares-mc    # Shares & market cap
python scripts/init_data.py --step cache        # Warm cache
python scripts/init_data.py --step sector-history  # Historical multiples
```

### 2. Create Unified Sector Analysis Script

**`scripts/sector_analysis.py`** - Single script for all sector operations:

```bash
# Calculate and store current multiples
python scripts/sector_analysis.py refresh

# Calculate historical multiples for year
python scripts/sector_analysis.py historical --year 2024 --store

# Generate timeline report
python scripts/sector_analysis.py timeline --years 2016-2024 --format html

# Show trend analysis
python scripts/sector_analysis.py trend --sector Technology --metric pe
```

### 3. Deprecate/Moved Scripts

**Move to `scripts/deprecated/`:**
- `generate_sector_timelines.py` → replaced by `sector_analysis.py timeline`
- `generate_multiples_timeline.py` → replaced by `sector_analysis.py timeline`

**Keep as-is (no overlap):**
- All RL scripts (`rl_*.py`)
- All CLI tools (`*_cli.py`)
- `batch_warm_sec_cache.py` → or integrate into `init_data.py`
- `sec_data_extractor.py` → or integrate into `init_data.py`
