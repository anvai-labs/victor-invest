## Key Frameworks

### Balloon Effect
- **Inflating:** Multiple expansion (NVDA 2023-24)
- **Deflating:** Multiple compression (META 2021-23)
- **Stubborn:** Flat multiple (AAPL 2019-24)

### Size Premium
| Cap Size | P/E Premium |
|----------|------------|
| Mega (> $200B) | +15% |
| Large ($50-200B) | +8% |
| Mid ($10-50B) | 0% |
| Small ($2-10B) | -12% |
| Micro (< $2B) | -25% |

### Three Regimes
1. **2015-2019:** Low volatility, steady growth
2. **2020-2021:** COVID bubble, extreme expansion
3. **2022-2024:** Rate hikes, multiple compression
