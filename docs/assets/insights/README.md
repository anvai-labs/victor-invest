## Key Insights Summary

### 1. The Tech Bubble Burst (2016-2024)
- P/E: 116x → 31x (-73%)
- P/S: 17x → 3x (-83%)
- **But:** Earnings grew 3-5x, many stocks still went up
- **Lesson:** Multiple compression ≠ Stock price decline IF earnings grow fast enough

### 2. The Energy Renaissance (2020-2025)
- P/E: 7x → 18x (+143%)
- **Driver:** Oil prices + inflation + supply shock
- **Lesson:** The most hated sector becomes the most loved (eventually)

### 3. Size Premium is Real (and Large)
- Tech size premium: 531% (Micro vs Mega)
- Energy size premium: 69% (commodities don't care)
- **Lesson:** Small caps are risky but offer 40-80% discounts

### 4. P/S Tells the Truth (When P/E Lies)
- Tech P/S: 17x → 3x (-83%)
- **Driver:** Revenue quality matters more in high-rate world
- **Lesson:** In high-rate environments, discount distant earnings, not current revenue

### 5. The Balloon Effect
- **Expansion:** Multiple ↑ + Earnings ↑ = Magic (Tech 2016-2020)
- **Compression:** Multiple ↓ + Earnings ↑ = Leaking (Tech 2021-2024)
- **Contraction:** Multiple ↓ + Earnings ↓ = Pop (Cyclical downturns)
- **Lesson:** Know which phase we're in

## Data Notes

### Data Quality
- **Source:** SEC Company Facts API (filings, not estimates)
- **Sample Size:** 3,000+ companies with sec_companyfacts_processed records
- **Coverage:** All US-listed companies with SEC filings (includes foreign private issuers filing Form 20-F)
- **Accuracy:** Filings data, not estimates (may lag real-time by 1-2 quarters)

### Limitations
- **P/E limitations:** Many small/micro caps are unprofitable (P/E not meaningful)
- **Foreign issuers:** Some companies (TSM, ASML) don't file US-standard forms
- **Timing:** Fiscal year data may be 6-12 months behind calendar data
- **Survivorship:** Current data only covers companies still operating (no failed companies)

### Methodology
- **Median used:** Outlier-resistant (extreme valuations don't skew)
- **Percentile ranks:** For out-of-sample companies (not included in calculations)
- **Minimum samples:** Sectors/industries with <5 companies excluded
- **Fiscal year alignment:** Uses SEC fiscal year (not calendar year)
