## 🏦 Sector-Specific

### Banks (P/B by ROE)

```
ROE ≥ 15%  → P/B 1.75x
ROE 10-15% → P/B 1.25x
ROE < 10%  → P/B 0.90x
```

### Insurance (Combined Ratio)

```
<90%     → P/B 1.3-1.5x (Excellent)
90-95%   → P/B 1.1-1.3x (Good)
95-100%  → P/B 0.9-1.1x (Acceptable)
```

## ⚠️ Model Rules

```
┌─────────────────────────────────────────────────────────────┐
│  Model       │  Required                      │  Condition   │
├─────────────────────────────────────────────────────────────┤
│  P/E         │  Net Income > 0               │  Positive    │
│  EV/EBITDA   │  EBITDA > 0                   │  Positive    │
│  DCF         │  FCF available                │  4+ qtrs     │
│  GGM         │  Dividends + NI > 0           │  40% payout  │
│  P/S         │  Revenue > 0                  │  Any         │
│  P/B         │  Book Value > 0               │  Positive    │
└─────────────────────────────────────────────────────────────┘
```
